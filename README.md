# Odyssey-Resource-Pack

Welcome! This Minecraft pack is a passion project filled with my own custom ideas, configurations, and designs. 

A huge part of making something cool is pulling from the things that inspire you. This pack wouldn't be what it is without the incredible work of some amazing creators in the community.
